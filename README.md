# Duck Studio Suite

Suite de produccion musical web del universo Duck.

## Que es

Un conjunto de herramientas de estudio pensadas para el navegador, dentro del ecosistema Duck.
La suite agrupa modulos de produccion y los presenta bajo una identidad comun.

En linea: <https://belentani7.github.io/duck-studio-suite/>

## Stack

- **Vite + TypeScript** - base
- **Tailwind + shadcn/ui** - interfaz (`components.json`)
- **GitHub Pages** - publicacion

## Puesta en marcha

```bash
pnpm install
pnpm dev
```

## Nota

La raiz redirige a `ecosistema.html`: `index.html` quedaba vacio y la redireccion evita una
pagina en blanco.
